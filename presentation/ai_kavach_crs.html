Step 2 · Prove

Six self-validating oracles

Differential

SQL and NoSQL. A reflected echo cannot flip true versus false.

Marker

The result of the attack, absent from the payload. 31338, 1337, root:x:0:0.

OOB callback

The target hits a one-time loopback listener. The callback decides.

Two-user

IDOR and BOLA. Authorized versus unauthorized, own versus foreign id.

Content facts

Headers, cookies, CORS, JWT, rate-limit. A fact or a unique marker read back.

Timing

Request smuggling. Probabilistic, so candidate only, never confirmed.

A static flag becomes a proven bug by mapping file to route and resolving the parameter. No LLM in the proof loop.

Step 3 · Fix

Deterministic first, LLM last

Tier 1

Templates

Literal swaps. MD5 to SHA-256, Random to SecureRandom. Always compile.

Tier 2

Config fixes

9 classes across Express, Spring, Flask, Django, Rails.

Tier 3

Gated LLM

One function rewritten by AST, only where no safe template exists.

Zero model variance on tiers 1 and 2. Dependency bugs are reported, never version-bumped.

Step 4 · Verify

A fix passes four checks

1

Replay the real exploit. Still fires? Rejected.

2

Observed good traffic still returns the same answers

3

Re-scan: the bug class is gone, not just one input

4

Every twin call site surfaced, so the scope is honest

The regression set is derived from the app's own traffic, never model-invented. Six audit artifacts per run, every exploit replayable.
