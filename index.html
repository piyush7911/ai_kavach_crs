SYS.LOG // 01 · THE PROBLEM
Why automated repair fails on real C/C++
Three fundamental limitations of standard AI tooling on production-grade codebases.
Context blindness
LLMs evaluate snippets in isolation — blind to nested typedef chains, packed bitfields, and header-level struct definitions.
Hallucination & rubber-stamping
Generated patches fail to compile, or silently disable security checks without ever verifying the crash is resolved.
Overfitting & gutting
Patches over-fit to the exact crashing input (if(x==4)return;) or gut functionality with an early return.

PHASE 1 & 2 · DETECTION + CONTEXT
Dual-path detection & AST triage
Static and dynamic analysis run side by side, enriching vulnerabilities with Tree-sitter AST context.
Static — Semgrep
  • Pre-configured, high-precision rulesets
  • Generates standardized SARIF v2.1.0 reports
Dynamic — libFuzzer & AFL++
  • Instrumented with ASan + UBSan
  • Unified harness catching memory faults at runtime
CRASH TRIAGE & DEDUP
Clusters thousands of raw fuzzer crashes into one canonical report per root cause (e.g. CWE-416).
TREE-SITTER AST WALK
Extracts parent struct, typedef chains, and bitfields to provide the agent complete compilation context.

PHASE 3 · AGENTS
Multi-agent ensemble — three specialists, one race
All three agents run in parallel on the same context; among the ones that clear every gate, the smallest patch wins.
AGENT ALPHA
The Analyst
Chain-of-Thought reasoning explains why the flaw occurs first. Specialised for multi-variable state bugs, integer truncation, underflows.
AGENT BETA
The Minimalist
Constrained to the smallest valid AST modification — a single bounds or null check. Specialised for OOB reads/writes and leaks.
AGENT GAMMA
The SARIF Patcher
Handles static-analysis findings directly — e.g. swapping strcpy for snprintf, fixing format specifiers.
DUAL PATCH FORMAT
Unified diff for line-based edits, or whole-function AST splicing to eliminate wasted iterations from line-drift.

PHASE 3 · THE CRITIC
Agent Delta — Diagnostic LLM-as-judge
Invoked only when a patch fails a DRV gate. It parses the raw AddressSanitizer stack trace or failing PoV output, and returns a structured diagnostic verdict — resolving the oscillation loops that plague raw-feedback agents.
